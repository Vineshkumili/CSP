# Vignan Virtual Assistants

A web-based virtual assistant platform developed for Vignan's Institute of Information Technology to provide students with quick access to college-related information and services.

## 📌 Project Overview

The Vignan Virtual Assistants platform is designed to provide students with a centralized system for accessing college information and interacting with different student services.

The system consists of multiple modules that simplify common student queries and administrative interactions.

---

## ✨ Features

### 🤖 Chatbot

- Provides answers to common college-related queries.
- Helps students quickly access information.
- Interactive chatbot interface.

### 🎓 Eligibility Checker

- Allows students to check admission eligibility.
- Takes entrance examination rank as input.
- Provides suitable college/branch information based on the given rank.

### 📝 Complaint Box

- Allows students to submit complaints or issues.
- Stores complaint information in the database.
- Sends complaint notifications to the concerned authority.

### 🏫 College Information

- Provides important information related to the institute.
- Centralized access to student services.
